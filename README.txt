# F1 Race Telemetry Analysis

This project analyzes Formula 1 telemetry data using Python and the FastF1 library.

The analysis compares the **fastest laps of George Russell, Kimi Antonelli and Charles Leclerc during the 2026 Australian Grand Prix**.

## Technologies

- Python
- FastF1
- Matplotlib
- Pandas

## Features

- Fastest lap comparison
- Telemetry analysis
- Speed vs distance visualization
- Clean data visualization
